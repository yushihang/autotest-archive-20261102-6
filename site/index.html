从这里开始

Web3 常被说得很玄，但它想解决的问题其实很朴素：让数据和身份不再只由某一家公司保管。 DID（去中心化身份）是其中最容易落地的一部分，它讨论的是「你自己持有身份凭证」这件事。 这套课程面向没有技术背景的读者，尽量不用公式和代码，用日常经验来解释这些概念。 你可以按顺序读，也可以只挑自己关心的那一篇；每篇都会在结尾给出下一步的阅读建议。 读完你至少能分清哪些是真实的能力，哪些只是营销话术。

学习路径

建议按下面的顺序阅读，后面的内容会用到前面的概念。

  1. 什么是 Web3：先弄清它和 Web1、Web2 的区别，以及它承诺解决什么问题。
  2. 什么是 DID：理解去中心化身份的基本模型，以及它和普通账号的区别。
  3. Web3 与 DID 的关系：看看身份为什么是 Web3 里绕不开的一环。
  4. 术语表：遇到不熟悉的词随时回来查，不必一次记住。
